# Differential Expression Analysis

Use this folder for the course's first project. Keep every part of the analysis here:

```text
data/raw/       # Downloaded source data; ignored by Git
data/processed/ # Derived data; ignored by Git
notebooks/      # Exploratory, ordered analysis
scripts/        # Repeatable steps
results/figures/# Generated figures; ignored by Git
```

Keep a record of:

- GEO accession and download instructions
- sample metadata and preprocessing decisions
- statistical method and thresholds
- plots, enriched pathways, and interpretation

Do not commit downloaded datasets. Put reproducible download or preprocessing commands in `scripts/` or a notebook.
